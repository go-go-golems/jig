Flatground

A skater rides a lot with a funbox in it. The autopilot pushes, carves round the course and plays a trick on each straight; press any key on the stage and you are riding instead. Everything you see — the rigid-body physics, the legs, the motors that flip the board, the recognizer that names the trick, the hairline drawing — is code in the Code view, and every file is yours to change.

Try it. Click the stage, hold ↑ to push, then press and release Space to ollie. Hold J while you release Space for a kickflip, I for a pop shove-it, J + I + Shift for a 360 flip. The trick pad on the right plays the same key gestures for you.

What is on the screen

The stage is a drafting sheet, not a game camera: an orthographic projection (parallel rays, no perspective) so lengths along each axis keep one scale, the one in the scale bar. Shadows are hatched like a pencil drawing; the ghost decks are an onion skin of the last jump, and the dimension line on the floor measures take-off to landing. Switch to the side elevation with Track on and the board is always seen in profile — the best view for flips.
