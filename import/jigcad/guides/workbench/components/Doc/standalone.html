A tour of the workbench

Form Skate Workbench is an IDE for one program: a skateboard game built on a small simulation framework, @form/core. Every part of the game — physics, legs, the motors that flip the board, the recognizer that names tricks, the drawing — is ordinary JavaScript in the Code view, and the workbench is built to let you change any of it while it runs and see what happened. Chapter 2 of the book is a longer tour.

The loop

  1. Read what's there: the preset's Notes, the Graph of systems, the IR.
  2. Change a file in Code, or a value in Params.
  3. Run (Ctrl+Enter). The program recompiles in a few milliseconds and the running world carries on with the new code: states and bodies are kept wherever their ids and types still match, the systems' private variables name by name (a variable the new code still declares takes its old value, whatever its type), and stateful signal nodes wherever their expression is unchanged. The footer says how many.
  4. Look: the Stage, the Traces, the Events. Or ask a question with many runs in Experiments.
  5. Or ask the Agent to do any of the above.

If the new code throws while running, the world stops at that step and the stage says where; fix it and press Run, and it resumes from the same moment.

Links in the notes

Underlined links with a ▸ act on the workbench. This one opens the pop motor; others pin a trace, select a node in the graph, play a trick, change the view, set a parameter, load a preset or open another document. You can write them in your own notes too (Notes → Edit); the syntax is in the Reference.
