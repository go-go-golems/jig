A tour of the workbench

Form Skate Workbench is an IDE for one program: a skateboard game built on a small simulation framework, @form/core. Every part of the game — physics, legs, the motors that flip the board, the recognizer that names tricks, the drawing — is ordinary JavaScript in the Code view, and the workbench is built to let you change any of it while it runs and see what happened. Chapter 2 of the book is a longer tour.
