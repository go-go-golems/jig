Chapter 47

Drawing motion

A kickflip lasts half a second; a drawing of it lasts as long as anyone looks at it. This chapter puts time into a still image. The stage does it in three ways: it draws past poses of the board over the present one (an onion skin), it traces the paths that points of the board followed (a flight path), and it states the trick's length on the floor with a dimension line. A preset adds a fourth, the chronophotograph: the rider as a repeated stick figure, after the photographs Étienne-Jules Marey made of moving bodies in the 1880s. By the end you will know where the past poses come from, how each drawing is built from them, and how to read spacing as speed and the shape of a path as force. The preset is D-03 Onion skins and chronophotographs; the drafting context is the one of Chapter 43.

47.1 Time in a still image

A drawing of motion needs the poses at earlier moments and a rule for which to show, and the rule decides what the image says. Poses at equal intervals of time make speed visible as spacing: a fast part of the motion leaves its images far apart, a slow part crowds them. Poses at equal intervals of distance hide speed and show shape instead. Joining every moment gives a path, which loses the poses but shows the route exactly. The stage samples equal times throughout, and none of its motion views records anything for itself: they all read one memory.

47.2 The memory: the history buffer

The runtime keeps a history: after every second step, the pose (position and orientation) of every body, for the last eight seconds. Chapter 33 introduced it for repeatable runs; here it is the drawing's memory.

// core.js
class History {
  constructor(rt, seconds = 8, every = 2) { this.rt = rt; this.every = every; this.cap = Math.ceil(seconds / (rt.dt * every)); this.buf = []; }
  record() {
    if (!this.rt.world || this.rt.stepN % this.every) return;
    this.buf.push({ t: this.rt.time, bodies: this.rt.world.poses() });
    if (this.buf.length > this.cap) this.buf.shift();
  }
  between(t0, t1) { return this.buf.filter(s => s.t >= t0 && s.t <= t1); }

The capacity is eight seconds at one sample every two steps of 1/120 s, 8/(2/120)=4808 / (2/120) = 480 samples. record runs after every step and keeps only even-numbered steps, so samples fall on multiples of 1/60 s; when the buffer is full the oldest is dropped. Each sample holds world.poses(), a map from body id to { p, q }, so a view can ask where the deck, the hips or a foot was at any remembered moment. between returns the samples in a time window, and views reach the history as ctx.history.

47.8 Key points

  • A drawing of motion shows several moments at once; sampling equal times makes speed visible as spacing.
  • The history keeps every body's pose every second step for eight seconds (480 samples, 1/60 s apart); motion views read the window of the current or last trick with ctx.history.between.
