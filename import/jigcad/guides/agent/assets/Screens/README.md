- `agent-ask-dark.png` — 518 × 848, dark, the Agent tile only. Ask mode with Deep and High thinking: a step waiting for approval, open, with Run this step and Decline, and Stop in the composer.
- `agent-empty-light.png` — 518 × 848, light, the Agent tile only. A new thread's empty state with B-01's suggestions.
